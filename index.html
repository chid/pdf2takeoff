The tool

What is pdf2takeoff?

pdf2takeoff is a free, open-source tool that turns construction PDF drawings into measured quantities. Auto-read the scale with OCR, measure lengths, areas, perimeters, volumes and angles, auto-count repeated symbols, then export to Excel or save markups back into the PDF. It runs entirely in your browser — and the same engine ships as a CLI and MCP server, so scripts and AI agents can run takeoffs too. Drawings are never uploaded.

Workflow

How to do a takeoff from a PDF, free

  1. 1Open the drawing. Drag any PDF into the window. Rendering happens on your machine; nothing is sent to a server.
  2. 2Calibrate the scale. Click both ends of a printed dimension and hit Auto-read — OCR fills in the value straight off the sheet — or pick a standard scale like 1:100.
  3. 3Measure. Trace wall runs with Length, outline rooms with Area, take Perimeter and Volume (area × depth), click Count for fixtures — or press Scan to count every instance of a symbol at once. Each page keeps its own scale.
  4. 4Export quantities. The markups list groups by label with running totals. Copy it into Excel or download the CSV.
  5. 5Save into the PDF. Markups are written as standard PDF annotations, so the annotated file opens cleanly in Bluebeam Revu, Adobe Acrobat and every other PDF app.

Estimators shouldn't need a per-seat licence to count light fixtures.

An open core means builders and developers can add trade-specific tools (HVAC, rebar, electrical) and AI takeoff helpers without asking permission. The headless engine, CLI and MCP agent API already ship; next on the roadmap are live multi-user sessions and a trained in-browser symbol detector.

FAQ

Frequently asked questions

Is it really free? What's the catch?

There is no catch and no paid tier. The project is Apache-2.0 licensed open source; hosting is a static page, so there is nothing to meter.

Are my drawings private?

Yes. The tool is a static web page: your browser renders the PDF and computes every measurement locally. Tender documents never leave your machine.

Will my markups show up in Bluebeam Revu?

Yes, that's the point. Measurements are saved as standard Line, PolyLine, Polygon and FreeText annotations with values in the comments, so they appear in Bluebeam's markups list and can be exported from there to Excel as usual.

What can't it do yet?

Live multi-user sessions and ML detection for cluttered sheets are on the roadmap. Today it covers lengths, areas, perimeters, volumes and angles, OCR scale reading, CSV/Excel export, annotation round-tripping, revision overlay compare, batch folder compare, and a click-to-teach Scan that auto-counts repeated symbols locally in about a tenth of a second.

Can AI agents or CI pipelines use it without the browser?

Yes — that's the headless half. pdf2takeoff on Node gives you scan, compare (files or whole folders), export and annotate; a committed takeoff.yaml regenerates quantities on every revision; and the local MCP server lets agents like Claude drive full takeoffs and hand you a marked-up PDF to verify. All local, Apache-2.0, no uploads — where Bluebeam's Max tier charges AU$979/user/yr for MCP integration.

Does it work offline?

Once the page has loaded, no network access is needed. You can keep working through an outage.
